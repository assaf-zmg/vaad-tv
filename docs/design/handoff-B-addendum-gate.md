# תוספת למסירה B: תיקונים מבדיקת השער

**מאת:** עיצוב לועד-TV. **אל:** פיתוח לועד-TV. תשובה לשתי השאלות מבדיקת השער (screens-gate-2).

## 1. הודעה ארוכה בזמן התרעה, במסך נמוך (1280×720)
**הבעיה:** הודעה עם כותרת של 2 שורות וגוף של 6 שורות התחלקה ל-9 חלקים × 20 שניות, כלומר 3 דקות לקרוא הודעה אחת.
**ההחלטה:** במסך נמוך, בזמן התרעה, **כרטיס החדשות מוסתר** וכל הגובה שלו עובר להודעת הוועד. בחירום ההודעה של הוועד (למשל, הנחיות למקלט) חשובה מחדשות טובות. ב-1920 לא משתנה כלום.
**תוצאה (נמדד):** אותה הודעה, עם כותרת של 2 שורות, נכנסת במלואה בעמוד אחד, בלי חלוקה (כרטיס 261px בקופסה של 269px). צילום: `gate-check-1-alert-1280-long-ann.jpeg`.

**CSS:** להוסיף בסוף `style.css` את `docs/design/handoff-gate.css` (גם סעיף 2 נמצא שם).

**JS** (`renderNewsPage`): לא למדוד כשהכרטיס מוסתר. מיד אחרי `var el = els.newsContent;`:
```js
if (!el.offsetWidth && !el.offsetHeight) return; // card hidden (alert on a low screen)
```
כשההתרעה נגמרת, `render()` בפולינג הבא מחזיר את הכרטיס ובונה מחדש את העמודים.

## 2. קרדיט התמונה בפינה
**הבעיה:** 17px בלי רקע נעלם על סלע בהיר או שלג (01-normal-day, 05-snow).
**ההחלטה:** גלולה כהה קטנה מאחוריו (`rgba(0,0,0,.45)`, ריפוד 3px 10px, פינות 6px). הטקסט קצר מאז D25, אז זה לא מוסיף רעש.

## אימוג'י הירח למחר
התיקון בשרת (סמלים יומיים תמיד `_day`) נכון. "עכשיו" ממשיך להציג ירח בלילה, כמתוכנן.

## 3. ברכת חג בזמן התרעה (נוסף אחרי הצילום מחדש)
בצילום 07 הופיע "חג עצמאות שמח!" ליד פס ההתרעה האדום. בזמן התרעה, בכל גודל מסך, ה-pill של חג או אירוע מוסתר, וחוזר כשההתרעה נגמרת:
```css
body.has-alert #photo-message { display: none; }
```
(נמצא גם בסוף `handoff-gate.css`.)
