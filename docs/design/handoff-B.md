## מה לעשות (3 שינויים, בלי שינוי HTML)
1. **CSS:** להחליף את `public/css/style.css` כולו בתוכן של `docs/design/handoff-B-style.css`.
2. **JS, `renderPhotoText`** (`public/js/dashboard.js`): לעטוף את ההודעה ב-pill. מיד אחרי השורה שמוסיפה את `msg-sub`, עוד בתוך ה-`if (bg.message)`:
   ```js
   msg = '<span class="msg-pill">' + msg + '</span>';
   ```
3. **JS, אייקון מזג אוויר:** בשורה שמחליפה את צבעי האייקון, `fill="#2b2b28"` → `fill="none"`. אין יותר רקע כהה מאחורי האייקון, וגוש כהה נראה רע על תמונה.
   ```js
   .split('fill="white"').join('fill="none"')
   ```

## מה השתנה בעיצוב
- התמונה ממלאת את כל `#main`, מקצה לקצה. אין מגירה כהה ואין כרטיסים.
- העמודה (`#sidebar`) צפה מימין: `top/right/bottom: 28px`, רוחב `500px`, `z-index: 6`. טקסט לבן, `text-shadow` אחד (`0 1px 4px rgba(0,0,0,.85)`), קווים מפרידים דקים בין החלקים.
- **הצללה לקריאות:** `#photo:after`, גרדיאנט מימין ברוחב `980px`, תחנות `.78 → .58 (40%) → 0`. נבדק על 3 התמונות הבהירות ביותר במאגר (נמדד: #15, #54, #51), על לגונת קרחונים (#25) ועל הכהה ביותר (#59).
- **התרעה אדומה:** פס מלא למעלה, בלי פינות, 40px. דוחף את כל המסך למטה.
- **ברכת חג/אירוע:** `.msg-pill` ממורכז באזור התמונה (משמאל לעמודה: `left: 28px; right: 556px; bottom: 70px`). חגיגי: 64px, משקל 800. **שקט (אבל/זיכרון):** 48px, משקל 500, רקע כהה יותר (.55).
- **פלאייר של ועד:** `#ann-photo` הופך למסגרת ממורכזת (`top/bottom/left: 40px; right: 568px`), `contain`, והשאר מעומעם (רקע + `box-shadow` spread של `.6`). העמודה מעל העמעום ונשארת בהירה.
- **קרדיט:** פינה שמאלית למטה, 17px, בלי קופסה. 23px מתחת ל-pill, נמדד, ואין התנגשות.
- **חדשות** בגובה טבעי, **הודעות ועד** תופסות את שאר המקום. הנקודות צמודות לתוכן.
